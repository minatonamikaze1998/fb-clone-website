## Overview
- Built with semantic HTML5 and CSS3 to replicate core UI components.
- Serves as a hands-on project to practice branch management, commits, and remote workflows in Git.
- Features a responsive layout designed to adapt across desktop and mobile screens.

## Getting Started
- Clone the repository locally using `git clone https://github.com/minatonamikaze1998/fb-clone-website.git`.
- Open `index.html` directly in any modern web browser to preview the interface.
